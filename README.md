# SQL Employee Database Project

Course capstone completed as part of the Microsoft Azure AI-Powered Business Analyst program (Simplilearn). It covers 11 tasks on an employee database in MySQL.

## Skills shown
- Filtering with WHERE, IN and BETWEEN
- Aggregates with GROUP BY (MIN, MAX, AVG, ROUND)
- Window functions: PARTITION BY and RANK
- Views (CREATE VIEW)
- Indexes and EXPLAIN to improve query performance
- CTEs

## Files
- `employee_sql_project.sql`: all 11 queries, with comments for each task
- `SQl Final Project.pdf`: report with results and screenshots

## How to run
Import the three tables (emp_record_table, data_science_team, proj_table) into a schema called `employee` using the MySQL Workbench Table Data Import Wizard, then run the script.

## Tools
MySQL Workbench 8.0
